# Contributing to NetMD

We love your input! We want to make contributing to NetMD as easy and transparent as possible, whether it's:

- Reporting a bug
- Discussing the current state of the code
- Submitting a fix
- Proposing new features

## How to Report Bugs or Suggest Features

You can contribute in several ways:
1. **GitHub Issues**: Open an issue in the repository for bugs or feature requests.
2. **Pull Requests**: If you have a fix or a new feature, feel free to open a PR.
3. **Email**: You can also reach out directly to [apps@malagaonrails.com](mailto:apps@malagaonrails.com).

## Development Process

This project is designed to be simple and build-less.

1. Fork the repo and create your branch from `main`.
2. If you've added code that should be tested, add tests.
3. If you've changed APIs, update the documentation.
4. Ensure the test suite passes.
5. Make sure your code lints.
6. Issue that pull request!

## Any questions?

Feel free to contact us at [apps@malagaonrails.com](mailto:apps@malagaonrails.com).
